# Deskwork – React Router To-Do + Products

A small React app built with Vite.

- Product info component using props and state
- To-Do app with add, delete and tick-off (saved in localStorage)
- Multi-page navigation with React Router
- Styling with CSS Modules

## Run it

```bash
npm install
npm run dev
```

Open the link shown in the terminal (usually http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Structure

```
src/
  components/   Navbar, ProductInfo, TodoItem (each with a .module.css)
  pages/        Home, Products, Todo, About, NotFound
  data/         products.js
```
